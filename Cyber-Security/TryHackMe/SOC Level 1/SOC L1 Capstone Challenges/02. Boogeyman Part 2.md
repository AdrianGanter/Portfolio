## Conclusion
In this investigation I have established that the victim machine WKSTN-2691 was compromised when user Maxine opened a malicious document `Resume_WesleyTaylor.doc`

I began analysing the malicious document with terminal tool Olevba and revealed the document used macros to download a stage 2 payload from domain `boogeymanisback.lol` and then creates a shell called `wscript.exe` that executes the downlaoded stage 2 payload `update.js`

This payload then downloaded another malicious binary from a similar URL from the boogeymanisback domain called `update.exe` which executed the process `updater.exe` in /Windows/Tasks

This created a C2 connection, and using the vol tool and plugin netscan I was able to identify this connection between the host IP `10.10.49.181` and attacker IP `128.199.95.189`

Further analysis revealed the full file path of the malicious email attachement in the memory dump, and also a scheduled task was created using powershell and encoded commands to establish persistence.

- Broadened my knowledge around the Volatility tool in terminal, and the different plugins I can utilize to find the information I need
- More efficiency in initial phishing investigative process
- Strengthened my ability to detect C2 communication with the netscan plugin
