## Conclusion
From this investigation I was able to follow the chain of events of an attack where the threat actor gained initial access via a malicious ISO file that contained `review.dat`. The payload involved `mshta.exe` which spawned `xcopy.exe` to copy `review.dat` into the user Temp directory. The payload `review.dat` was executed through `rundll32.exe` which allowed the attacker create persistence through a scheduled task named `Review`

It was then observed a C2 connection was established between the threat actor and the host machine. The attacker discovered they were operating as a local administrator, so they utilised a UAC bypass technique with `fodhelper.exe` to help them with privilege escalation.

Now with higher privileges the attacker downloaded the Mimikatz tool from Github and began lateral movement by dumping credentials with the tool. Additionally they were able to dump another account's credentials through a DCSync attack.

To finish off, the attacker downloaded a remote file to execute the ransomware `boogeyman.exe`
